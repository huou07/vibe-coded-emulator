The [failed GitHub Actions run](https://github.com/huou07/vibe-coded-emulator/actions/runs/38370425290)
ran at source SHA `9624423b9de4838903ebc224561d13b901759c21` on
`feature/phone-controller-cross-platform`. Job logs were inspected.

- **Publication secret scan:** Gitleaks ran with the default configuration because
  the private workflow pointed at `.gitleaks.toml`, which did not exist at the
  checkout root. The scanner then reported known non-secret identifiers. Commit
  `08c944b` points both relevant workflow surfaces at the project config and
  keeps its two allowlists restricted to exact patterns and paths. Direct
  Gitleaks checks of those two identifiers with that config exited 0.
- **Python tests:** two Switch failure-path probes selected the macOS ARM64
  companion on an Ubuntu runner and failed with `Exec format error`. Commit
  `b5be4cd` scopes companion and MoltenVK candidates to macOS across the Switch
  process test modules. The tests skip when their real platform prerequisites
  are absent; the assertions are retained.
- **Documentation references:** a clean checkout did not materialize the ignored
  runtime `data/` directory, so `git status --ignored` omitted it and the
  checker incorrectly rejected existing references. Commit `5a132d5` checks
  configured ignore rules for known repository roots and adds a temporary clean
  repository regression test for absent `data/`.
- The public native workflow's Node test glob was also inconsistent with the
  actual `native-offline/tests/` contents. Commit `601ef93` includes shared
  `static/**` and `tests/**` in its path filters and removes the unmatched
  native Node glob. That directory contains native `.mm`/`.cpp` sources, not
  Node test suites.
