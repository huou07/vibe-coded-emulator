# Building

Prerequisites are per target. The web app needs only Python 3.10+ (standard
library); the native apps need Rust, Node.js and platform toolchains.

## Web app

No account is required to launch the Web app or play a locally selected ROM.
Account, password, cloud-sync and social features are not part of this public
product surface.

```bash
cp .env.example .env          # set only local server values if needed
python3 app.py                # serves on AN3_HOST:AN3_PORT (default 0.0.0.0:8091)
python3 -m unittest discover -s tests
```

The Web player uses EmulatorJS and per-core WebAssembly. Its checked-in runtime
assets and license notices are version-locked; the browser can play without an
account or a runtime CDN update-check request.

## Native desktop apps (macOS, Windows, Linux)

`native-offline/` is a Tauri 2 project with a shared portable libretro player
under `native-offline/native-runtime/`.

```bash
cd native-offline
npm ci

npm run build:macos                                   # macOS .app + DMG
bash scripts/build-android-staging.sh                 # Android APK (staging signing)
bash scripts/build-linux-staging.sh deb               # Debian package
bash scripts/build-linux-staging.sh flatpak           # Flatpak bundle
# Windows (PowerShell):
#   scripts/build-windows-runtime.ps1   (only when native-runtime sources change)
#   scripts/build-windows-staging.ps1
```

The pinned emulator cores are vendored in the development repository under
`native-offline/vendor/` (core binaries, their licence texts and a hash
manifest). This public snapshot carries the licence texts only: no core binaries
and no manifest, because the snapshot publishes source. The
`native-offline/scripts/fetch-*.mjs` helpers download and SHA-256 verify every
pinned core (mGBA, melonDS DS, Azahar) before bundling, and refuse bytes that do
not match the pin.

## Android notes

The Android project under `native-offline/src-tauri/gen/android` is generated by
`tauri android init`. Only the product-specific Kotlin, the manifest, the
network-security config and `build.gradle.kts` are kept here; regenerate the rest
with Tauri.

## Nintendo Switch (Eden) bridge

`native/eden-bridge/` is a C ABI bridge to Eden. It builds and its ABI is tested
without Eden; the Eden-backed backend is not yet runtime-verified. See
`docs/licensing/eden-integration-feasibility.md` and the bridge README.

## Public testing

This build is an unfinished public-test candidate, not a stable-release claim.
Accounts are not required. Missing physical-device or OS coverage stays
`UNVERIFIED` and does not block public testing. Identify the source SHA and
artifact hashes, retain third-party notices, preserve existing Web user data, and
run the published security/license checks. A rehearsed rollback is not a gate;
verify the candidate health and fix forward if it fails.
