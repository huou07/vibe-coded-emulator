Application settings

Shared by every system on this device. Core-specific settings live under Game Settings.

Game Settings

GBA, NDS, 3DS and Switch each keep their own Emulation and Graphics settings. Changing one system never changes another. Renderer changes apply on the next launch.

Sync

LAN Sync is a device-wide switch stored with the other application settings. It is never per-core and never stops the Phone Controller.

This offline app ships no LAN content-sync service yet, so no content type is advertised over the network. The switch gates native LAN sync when it is added and does not change the separate Phone Controller.
