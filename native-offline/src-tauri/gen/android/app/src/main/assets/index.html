Play a game

  1. Add a ROMChoose a GBA, NDS or 3DS file from this device.
  2. Open it from LibrarySelect the game, then choose Play.
  3. Use your controlsTouch controls, a gamepad or the keyboard.

ROMs and saves stay on this device.

Use another device

  1. Open DevicesEvery feature that talks to another device on this network lives on one screen.
  2. LAN SyncSend a save to another of your AN3 devices. Sign in first: a guest cannot prove the other device is yours, and a name clash always asks you which copy to keep.
  3. Phone ControllerStart hosting here, then type the six-digit code on the phone. Input is released the moment the pad loses focus or the connection drops.
  4. Nintendo SwitchShown only when this build bundles the Eden companion; games then open in that separate program.

Device-to-device traffic stays on this network. The AN3 server is never a relay.
