# Building

Prerequisites are per target. The web app needs only Python 3.10+ (standard
library); the native apps need Rust, Node.js and platform toolchains.

## Web app

```bash
cp .env.example .env          # fill in your own values
python3 app.py                # serves on AN3_HOST:AN3_PORT (default 0.0.0.0:8091)
python3 -m unittest discover -s tests
```

The web player uses EmulatorJS and per-core WebAssembly, loaded from the
configured EmulatorJS origin and cached in the browser.

## Native desktop apps (macOS, Windows, Linux)

`native-offline/` is a Tauri 2 project with a shared portable libretro player
under `native-offline/native-runtime/`.

```bash
cd native-offline
npm ci

npm run build:macos                                   # macOS .app + DMG
bash scripts/build-android-staging.sh                 # Android APK (staging signing)
bash scripts/build-linux-staging.sh deb               # Debian package
bash scripts/build-linux-staging.sh flatpak           # Flatpak bundle
# Windows (PowerShell):
#   scripts/build-windows-runtime.ps1   (only when native-runtime sources change)
#   scripts/build-windows-staging.ps1
```

Emulator cores are not vendored as binaries in this repository; the
`scripts/fetch-*.mjs` helpers download and SHA-256 verify the pinned upstream
cores (mGBA, melonDS DS, Azahar) before bundling.

## Android notes

The Android project under `native-offline/src-tauri/gen/android` is generated by
`tauri android init`. Only the product-specific Kotlin, the manifest, the
network-security config and `build.gradle.kts` are kept here; regenerate the rest
with Tauri.

## Nintendo Switch (Eden) bridge

`native/eden-bridge/` is a C ABI bridge to Eden. It builds and its ABI is tested
without Eden; the Eden-backed backend is not yet runtime-verified. See
`docs/licensing/eden-integration-feasibility.md` and the bridge README.
